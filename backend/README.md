# Welcome to **Diet Scanner**!

To run the backend, CD into the 'backend' folder and then in the terminal perform these commands:

```
uv sync
uv run fastapi dev src/backend/main.py
```

Then, in the frontend, CD into the 'mobile' folder and run these commands:

```
npm install
npx expo start
```

and you're good to go!

P.S. there is still a lot left that I haven't worked on yet, and soon enough I will be adding this to the App Store.
But for now, the MVP is done.
